A modern interactive digital portfolio built with React, TypeScript, and Three.js, featuring AI-powered content generation, project showcases, and immersive 3D visualizations.

---

## 🚀 Features

- **Interactive Portfolio Sections**: Hero, About, Skills with 3D visualization, Projects, Experience, Contact
- **AI-Powered Tools**: AI Chat Assistant, Content Generator, Analytics Dashboard, Project Recommendations
- **3D Graphics**: Three.js integration for stunning visual effects
- **Modern UI**: Built with TailwindCSS and Radix UI components
- **Backend Integration**: Supabase for data management
- **Responsive Design**: Optimized for all devices
- **TypeScript**: Full type safety throughout the application

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, TailwindCSS, Radix UI
- **Backend:** Supabase
- **Build Tool:** Vite

## 📦 Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/collins-muchiri/kamama-digital-canvas.git
    cd kamama-digital-canvas
    ```
2. **Install dependencies:**
    ```bash
    npm install
    ```
3. **Environment Setup:**
    Create a `.env` file in the root directory and add your Supabase credentials:
    ```
    VITE_SUPABASE_URL=your_supabase_url
    VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
    ```

4. **Start the development server:**
    ```
    npm run dev
    ```

## 🚀 Build & Deploy

- **Build for production:**
  ```
  npm run build
  ```

- **Preview production build:**
  ```
  npm run preview
  ```
